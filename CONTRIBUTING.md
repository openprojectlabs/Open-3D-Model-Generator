# Contributing

Thanks for helping improve Open 3D Model Generator.

## Development

Run a local static server:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Pull requests

Please:

1. Keep changes focused.
2. Test generation and every export format you touch.
3. Test desktop and narrow/mobile layouts when changing the UI.
4. Avoid adding large generated assets or `node_modules`.
5. Preserve the privacy-first, no-backend architecture unless a proposal explicitly changes that goal.
6. Update the README when user-facing behavior changes.

## Commit style

Clear, descriptive commits are preferred, for example:

`Add capsule procedural generator`
